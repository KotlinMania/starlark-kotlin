## What this file is

For every Rust crate vendored under `starlark-kotlin/tmp/`, this file lists:

- **Inbound callers** — every other `*-kotlin` repo's Rust source that brings a symbol from one of this repo's crates into scope via `use` or `pub use`, grouped by the imported symbol.
- **Re-export surface** — every `pub use` line this repo's crates emit, with source file:line and a flag marking the ones that live in `mod.rs` or `lib.rs` (the canonical re-export sites the migration rule targets).

**Granularity is import-level, not call-site-level.** A row shows that some other crate `use`'d the symbol; what that crate then *does* with the name (calls it, implements it, takes it as a generic bound, pattern-matches on it) lives in the importer's source body. For call-site detail, grep the listed importer files for the imported name. The graph tells you exactly which files to grep.

**Cross-repo only.** Imports between crates inside this same repo are omitted — those are intra-repo refactoring concerns, not the cross-project migration concern this file exists to surface.
